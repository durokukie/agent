# CLI 모듈

## 목적과 책임

명령행 인자를 해석하고 사용자 입력을 애플리케이션 요청으로 변환하며 실행 결과를 출력한다.

## 포함할 구현

CLI 명령, 옵션 검증, 스트리밍 출력과 사용자용 오류 표현을 포함한다.

## 공개 인터페이스와 사용 방법

패키지의 console script와 `python -m agent_system`이 호출할 단일 CLI 진입점을 제공한다.

## 의존성과 허용된 import 방향

`runtime`과 공용 `schemas`만 호출한다. LangGraph, persistence, 개별 에이전트를 직접 import하지 않는다.

## 데이터 및 제어 흐름

명령행 입력을 request로 변환해 runtime에 전달하고 반환된 event 또는 result를 터미널 형식으로 렌더링한다.

## 설계 결정과 제약사항

업무 로직과 agent 선택 로직을 포함하지 않는다.

## CLI 구현 규칙

- Python CLI의 사용자 출력은 Rich를 사용한다.
- 표, 진행 상태, 상태 메시지, 경고와 오류는 Rich의 구성 요소로 일관되게 표현한다.
- Rich 의존성은 이 모듈 내부에 한정하고, 업무 로직과 오케스트레이션 모듈이 Rich 타입에 의존하지 않도록 한다.
- 자동화와 테스트를 위해 색상 비활성화 및 비대화형 출력이 가능해야 한다.

## 테스트 전략

CLI runner로 인자 검증, 종료 코드, 표준 출력과 오류 출력을 검증한다.

## 변경 시 문서 갱신 조건

명령, 옵션, 출력 형식 또는 runtime 호출 방식이 바뀔 때 갱신한다.
