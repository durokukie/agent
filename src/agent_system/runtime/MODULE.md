# Runtime 모듈

## 목적과 책임

애플리케이션의 composition root로서 설정, 모델, 저장소, 도구, 에이전트와 오케스트레이터를 조립한다.

## 포함할 구현

애플리케이션 생성, 실행 수명주기, 의존성 주입과 자원 정리를 포함한다.

## 공개 인터페이스와 사용 방법

CLI와 향후 HTTP adapter가 공유할 실행 인터페이스를 제공한다.

## 의존성과 허용된 import 방향

필요한 모든 내부 모듈을 조립할 수 있는 유일한 위치다. 다른 모듈은 runtime을 import해 내부 의존성을 얻지 않는다.

## 데이터 및 제어 흐름

설정을 읽고 adapter와 registry를 생성한 뒤 orchestration 실행을 시작하고 결과를 호출자에게 돌려준다.

## 설계 결정과 제약사항

전역 singleton 대신 명시적인 생성과 주입을 사용한다.

## 테스트 전략

테스트 설정과 fake 의존성을 주입해 조립 결과와 자원 정리를 검증한다.

## 변경 시 문서 갱신 조건

애플리케이션 생성 방식, 수명주기 또는 조립 대상이 바뀔 때 갱신한다.
