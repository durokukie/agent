# Config 모듈

## 목적과 책임

환경변수와 설정 파일을 타입이 있는 애플리케이션 설정으로 변환하고 시작 시 검증한다.

## 포함할 구현

모델, 데이터베이스, logging, 실행 budget과 환경별 설정을 포함한다.

## 공개 인터페이스와 사용 방법

runtime이 한 번 설정을 로드하고 필요한 하위 설정을 각 모듈에 주입한다.

## 의존성과 허용된 import 방향

설정 라이브러리와 표준 라이브러리에만 의존한다. 업무 모듈이나 adapter를 import하지 않는다.

## 데이터 및 제어 흐름

환경 입력을 파싱·검증해 불변 설정 객체로 만들고 composition root로 전달한다.

## 설계 결정과 제약사항

비밀값을 기본값이나 로그에 포함하지 않는다. 누락되거나 잘못된 필수 설정은 실행 시작 전에 실패시킨다.

## 테스트 전략

기본값, 환경변수 우선순위, 타입 변환, 누락된 비밀값과 잘못된 범위를 검증한다.

## 변경 시 문서 갱신 조건

설정 항목, source 우선순위, validation 또는 비밀정보 정책이 바뀔 때 갱신한다.
