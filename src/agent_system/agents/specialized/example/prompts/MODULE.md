# 예제 전용 Agent Prompt 모듈

## 목적과 책임

예제 전용 agent가 소유하는 prompt를 해당 구현과 함께 관리한다.

## 포함할 구현

예제 agent 전용 시스템 prompt와 node별 prompt 자료를 포함한다.

## 공개 인터페이스와 사용 방법

예제 agent 내부 prompt loader만 사용한다.

## 의존성과 허용된 import 방향

다른 agent의 prompt를 직접 참조하지 않고 공통 조각이 실제로 필요할 때 명시적인 공용 위치를 설계한다.

## 데이터 및 제어 흐름

내부 node가 필요한 prompt를 선택해 모델 요청에 전달한다.

## 설계 결정과 제약사항

prompt와 이를 사용하는 node를 함께 변경하고 평가한다.

## 테스트 전략

렌더링 변수와 대표 입력에 대한 agent 행동을 검증한다.

## 변경 시 문서 갱신 조건

prompt 구성, 변수 또는 로딩 방식이 바뀔 때 갱신한다.
