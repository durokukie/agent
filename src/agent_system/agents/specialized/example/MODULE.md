# 예제 전용 Agent 모듈

## 목적과 책임

새로운 전용 agent를 추가할 때 따를 디렉터리 구조와 문서 작성 방식의 예시를 제공한다.

## 포함할 구현

향후 예제 graph, state, node와 prompt를 포함할 수 있으며 현재 실행 구현은 없다.

## 공개 인터페이스와 사용 방법

구현 시 상위 agent 공통 인터페이스를 만족하는 단일 adapter를 제공한다.

## 의존성과 허용된 import 방향

상위 agent 계약과 허용된 공용 모듈만 사용하고 다른 전용 agent나 orchestration에는 의존하지 않는다.

## 데이터 및 제어 흐름

표준 agent 요청을 예제 내부 state로 변환하고 graph 결과를 표준 agent 결과로 변환한다.

## 설계 결정과 제약사항

실제 agent를 만들 때 이 디렉터리를 그대로 복제하기보다 책임에 맞게 이름과 설계를 명시한다.

## 테스트 전략

구현이 추가되면 공통 contract test와 graph routing 테스트를 작성한다.

## 변경 시 문서 갱신 조건

전용 agent의 권장 기본 구조가 바뀔 때 갱신한다.
