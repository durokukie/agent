# 내장 Tools 모듈

## 목적과 책임

프로젝트가 기본으로 제공하는 구체 tool adapter를 관리한다.

## 포함할 구현

하나의 파일 또는 하위 모듈마다 책임이 분명한 내장 tool을 둔다.

## 공개 인터페이스와 사용 방법

모든 구현은 상위 `tools` 계약을 만족하고 runtime에서 registry에 등록한다.

## 의존성과 허용된 import 방향

상위 tool 계약과 필요한 외부 SDK만 사용한다. agent와 orchestration에는 의존하지 않는다.

## 데이터 및 제어 흐름

검증된 tool 입력을 외부 동작으로 변환하고 표준 결과 또는 표준 오류로 반환한다.

## 설계 결정과 제약사항

파일 시스템 변경이나 외부 전송 같은 부수 효과를 명시하고 최소 권한을 적용한다.

## 테스트 전략

각 adapter의 정상·오류·timeout·권한 경로와 상위 contract 준수를 검증한다.

## 변경 시 문서 갱신 조건

내장 tool 목록, 부수 효과 정책 또는 등록 방식이 바뀔 때 갱신한다.
