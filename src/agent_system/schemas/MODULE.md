# Schemas 모듈

## 목적과 책임

여러 모듈이 공유하는 안정적인 요청, 결과, event 데이터 계약을 정의한다.

## 포함할 구현

애플리케이션 요청·결과와 모듈 사이에 실제로 공유되는 값 타입만 포함한다.

## 공개 인터페이스와 사용 방법

호출자는 명시된 schema를 생성하거나 반환값으로 소비한다. 각 필드의 의미와 불변 조건을 타입 가까이에 기록한다.

## 의존성과 허용된 import 방향

내부 업무 모듈에 의존하지 않는다. 여러 모듈이 schemas를 사용할 수 있지만 편의를 위한 잡다한 타입 저장소로 만들지 않는다.

## 데이터 및 제어 흐름

CLI 입력이 request schema가 되고 실행 결과와 event가 result schema를 통해 전달된다.

## 설계 결정과 제약사항

한 모듈에서만 쓰는 타입은 그 모듈 안에 둔다. 공유 필요가 확인된 타입만 이곳으로 이동한다.

## 테스트 전략

validation, 직렬화, 하위 호환성과 잘못된 입력의 오류 메시지를 검증한다.

## 변경 시 문서 갱신 조건

공유 schema, 필드 의미, 직렬화 형식 또는 호환성 정책이 바뀔 때 갱신한다.
