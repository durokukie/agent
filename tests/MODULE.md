# 테스트 영역

## 목적과 책임

공개 인터페이스의 동작과 모듈 조합을 검증해 안전한 변경을 지원한다.

## 포함할 구현

단위 테스트, 통합 테스트와 공유 fixture를 포함한다.

## 공개 인터페이스와 사용 방법

개발자는 `python -m unittest discover -v`로 전체 테스트를, 모듈 경로를 지정해 대상 테스트를 실행한다. 하위 테스트 디렉터리는 독립 PR에서도 표준 discovery가 재귀 수집할 수 있도록 Python package marker를 유지한다.

## 의존성과 허용된 import 방향

테스트는 `agent_system`의 공개 인터페이스를 우선 사용한다. 제품 코드는 tests를 import하지 않는다.

## 데이터 및 제어 흐름

fixture가 결정 가능한 입력과 adapter를 제공하고 테스트가 관찰 가능한 결과와 부수 효과를 검증한다.

## 설계 결정과 제약사항

구현 세부사항보다 seam의 계약과 사용자 관점 동작을 검증한다.

## 테스트 전략

빠른 단위 테스트와 실제 모듈 조합을 확인하는 통합 테스트를 분리한다.

## 변경 시 문서 갱신 조건

테스트 분류, 실행 명령, fixture 정책 또는 품질 기준이 바뀔 때 갱신한다.
